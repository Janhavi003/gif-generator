# GIF Generator (Python + Streamlit)

A modern, user-friendly web application to convert **images or videos into optimized GIFs** using Python.  
Designed with a clean UI, automatic media optimization, and forward-compatible APIs — making it **resume and portfolio ready**.

---

## Features

### Images → GIF
- Upload **one or multiple images**
- Automatic image resizing to reduce GIF size
- Preview images in a responsive grid before generation
- Supports **single-image looping GIFs**
- Adjustable frame duration

### Video → GIF
- Convert videos into GIFs
- Adjustable FPS, width, and maximum duration
- Automatic trimming and resizing
- Side-by-side preview: **original video vs generated GIF**

### UI & UX
- Clean, step-based workflow (Upload → Settings → Result)
- Responsive previews
- No deprecated Streamlit APIs
- Optimized for readability, usability, and performance

---

## Tech Stack

- **Python 3.12**
- **Streamlit** – Web interface
- **Pillow (PIL)** – Image processing
- **MoviePy 2.x** – Video processing
- **imageio-ffmpeg** – Video decoding backend
