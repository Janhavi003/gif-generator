# 🎞️ GIF Generator with Python

A clean and simple web app to generate GIFs from images or videos using Python.

## 🚀 Features
- Images → GIF conversion
- Video → GIF conversion
- FPS, size & duration controls
- Clean and minimal UI
- Download generated GIF

## 🛠️ Tech Stack
- Python
- Streamlit
- Pillow
- MoviePy
